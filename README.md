# PRISM 棱镜

每日更新的全球女性主义与 LGBTQIA+ 新闻与研究站。

网站做的事情很简单：搜集各地相关的新闻和公开研究，为每一条写一段**简短总结**，
再附上**报道这条新闻的媒体链接**。读者顺着链接自己去读原文，事实核查由站长自己承担，
网站不下任何「是真是假」的结论。

配套一个**两页的控制端**：一页启动搜集，一页编辑。

---

## 先看看长什么样

不想装任何东西：双击仓库根目录的 **`PRISM-prototype.html`**，浏览器直接打开，
整个网站（含控制端）都在这一个文件里。

> 这个文件是**某一次构建的快照**，不会自己跟着代码更新。
> 改过代码之后想要一份新的，运行 `npm run single`。线上版本以 GitHub Pages 为准。

想在本地跑开发版：

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

## 网站结构

**公众站**

| 地址 | 是什么 |
| --- | --- |
| `#/` | 今日：站长指定的头条，加上全部新闻，按地区和议题筛 |
| `#/news/:slug` | 一条新闻：总结、要点、所有媒体链接 |
| `#/region/:key` | 某个地区的全部条目 |
| `#/topic/:key` | 某个议题的全部条目 |
| `#/studies` | 研究与公开数据 |
| `#/about` | 关于 |

**控制端**（`#/console`）只有两页：

- **找新闻** — 选地区和议题，按一个大按钮就开始搜。找到的可以直接上线，也可以先存草稿。
- **编辑** — 三个标签：内容 / 外观 / 账号与同步。
  「内容」里能自己写新条目，也能改、下架、永久删除搜来的每一条。

## 一条新闻长什么样

```
标题
总结（想写多长写多长，几百上千字都行，空一行分段）
几条要点
原始文件：判决书、法案、数据集……
媒体报道：报道这条新闻的媒体，每条都能点开
```

长总结在首页信息流里收起，下沿渐隐并带一个「读全文」，点进去看全部。

一条新闻可以同时挂**多个地区标签和多个议题标签**——一份跨国报告本来就属于好几个地方。

**头条由站长指定**，不是算法挑的：在编辑页任意一条上按「设为头条」，它就上首页最上面那个位置。
头条一次只有一条，设了新的旧的自动让位；下架一条就自动不再是头条。
没有指定时，首页用最新的一条顶上，不会开着一个空位。

中东与北非 · 撒哈拉以南非洲 · 拉丁美洲 · 俄罗斯与中亚 · 跨区域/国际机构。

其中六个（中国内地、香港、台湾、日韩、美国、欧洲）在搜集时会先扫。
这是站长的搜集顺序，只在控制端里出现——公众站上地区就是地区列表，
不告诉读者网站内部怎么排先后。

## 两种运行方式

打开时自动判断，依据是 `public/prism-config.json` 里有没有填后端信息。

| | 本地模式（默认） | 共享模式 |
| --- | --- | --- |
| 内容存在哪 | 这台浏览器 | 共用的 Postgres |
| 别人打开你的网址 | 看到演示数据 | 看到跟你一样的内容 |
| 谁能看 | 谁都能看 | 谁都能看（有链接就行） |
| 谁能改 | 打开的人 | 只有站长和你指定的编辑 |
| 权限靠什么把关 | 界面判断（能绕过） | 数据库强制执行（绕不过） |
| 登录 | 不需要 | 邮箱链接，不用密码 |

**要把网站分享给朋友，看 [docs/SHARING.md](docs/SHARING.md)** ——
接一个免费的 Supabase，十五分钟，只做一次。

共享模式下有三种身份：**站长**（唯一，删不掉也降不了级，只有他能增删成员）、
**编辑**（能改内容，不能动名单）、**只能看**。
Supabase 是按需加载的，本地模式下读者不会下载它。

## 登录与权限

**本地模式没有登录。** 内容只存在这台浏览器里，没有第二个人，
所以打开的人就是这份副本的主人。这不是漏洞：他改的只是自己屏幕上的东西，
真正发布出去还要 GitHub token。

**共享模式用邮箱链接登录**——输入邮箱，收一封信，点链接。
不用设密码，不用 Google 账号。三种身份：

| 身份 | 能做什么 |
| --- | --- |
| **站长** | 全部。唯一能增删成员的人。删不掉，也降不了级 |
| **编辑** | 改内容、发内容、启动搜集。不能动名单 |
| **成员** | 跟没登录的人一样能看。登录只是为了让站长知道是谁、以后能发通知 |

**看内容不需要登录**——有链接就能看，这是站长要的分享方式。
链接因此就是全部的门禁：转发给谁，谁就能看。站点设了 `noindex` 和
`robots.txt`，正经的搜索引擎不会收录，但那挡不住转发。

**写入是另一回事**：一律要求站长或编辑，由数据库的 row-level security
强制执行，改浏览器里的代码没有用。**成员名单和编辑日志也锁着**——
名单里是朋友们的邮箱地址，那是他们的个人信息，不是站点的。

代码里**不写死任何人的邮箱**：谁是站长来自数据库，
所以发布出去的文件里没有任何人的地址。发布流程里的 `npm run privacy`
会扫一遍产物，出现邮箱地址就不给发布。

## 内容与外观

- 四套主题（暖纸 / 白纸 / 深色 / 高对比），五种强调色，五档字号，黑体/宋体，宽窄行距。
- 公众站右上角「外观」和控制端「编辑 → 外观」调的是同一套设置，读者也能自己调。

## 存回 GitHub

「编辑 → 账号与同步」里填一个 GitHub token（只需要 Contents 的写权限），
就能把当前所有内容存回仓库。存的是一个**内容文件**（`site-content.json`），不是代码，
所以同步不会弄坏网站。token 只存在你自己这台电脑的浏览器里，不会进同步文件。
没有 token 也没关系——旁边有「下载文件」，下载下来自己上传即可。

## 安全与隐私

- **[docs/RENAME.md](docs/RENAME.md)（中文）** — **网址里为什么有你的账号名，怎么换掉。**
  GitHub Pages 的网址格式是 `账号名.github.io/仓库名/`，那个名字不来自代码，
  改代码去不掉它。这一篇是全程点鼠标的做法：建一个免费组织、把仓库转过去，
  网址就变成 `组织名.github.io/prism/`；想连 `github.io` 都去掉，后半篇讲自有域名。
- **[docs/DEPLOY.md](docs/DEPLOY.md)（英文）** — 从零到上线的完整操作流程：
  去个人化的账号与组织、发布、自有域名、Cloudflare Access、token 权限。
  按钮名称与英文界面一致，照着点即可。
- **[docs/SECURITY.md](docs/SECURITY.md)（中文）** — 讲清楚每一步在防什么，
  以及哪些事其实不用担心。

一句话版本：控制端的登录是**界面上的**判断，懂技术的人能绕过去看到界面；
但他改不了你发布的网站——真正更新内容需要 GitHub token，那串东西只在你的浏览器里，
从来没进过发布出去的文件。要连界面也挡住，需要一个自己的域名加 Cloudflare Access
（服务端拦截，免费），手册里写了每一步。

## 发布到网上

仓库里带了 `.github/workflows/pages.yml`。第一次使用前，去仓库的
**Settings → Pages**，把 **Source** 选成 **GitHub Actions**。之后每次推送代码，
网站会自己重新发布。发布前会先跑数据检查和行为测试，不通过就不发布。

## 演示数据

仓库里现在装的是**演示数据**，条目、媒体名称与链接全部虚构，用于展示界面。
所有演示链接都落在保留域名 `.invalid` 上，永远不会解析，在页面上显示为不可点击的
「示例」，不会被误当成真实引用。接入真实检索后，真实链接会正常显示为可点击的链接。

公众站顶部有一条「演示数据」提示条，接入真实内容后会自动消失。

## 开发

```bash
npm run dev           # 开发服务器
npm run build         # 类型检查 + 构建到 dist/
npm run check         # 类型检查 + 数据检查 + 59 项行为测试
npm run privacy       # 扫一遍构建产物，出现邮箱地址就不给发布
npm run ui-check      # 用真实浏览器走 10 条路由 × 3 个视口（要先 build）
npm run console-check # 用真实浏览器在控制端里点和打字（要先 build）
npm run single        # 生成单文件 PRISM-prototype.html
npm run artifact      # 打包成一页，用于 claude.ai artifact
```

`ui-check` 只把每条路由打开看有没有渲染，`check` 只测纯逻辑——两者中间有个洞：
**没有人真的在输入框里打过字**。站长报的「给 publishable key 输入任何东西都出错」
就掉在那个洞里（那不是校验提示，是整个控制端崩到错误页）。`console-check` 专门补这一段：
像人一样一个键一个键地敲，然后确认没崩、东西真的存下来了、该拦的还拦着。

`npm run check` 是真正的门槛，不是摆设。它会挡住这些事：

- 一条新闻没有任何链接（读者没法自己去核对）
- 演示条目用了看起来像真的网址
- 一份研究没写「这份研究说不了什么」
- 站长被从管理员名单里删掉
- 同步文件里混进了 GitHub token
- 撤销一次搜集之后没有把这次加的全部收回
- 同时有两条头条，或者头条是下架状态（读者看不到）
- 接上登录之后，不在管理员名单里的账号还进得去控制端
- 打开取材规则之后，官方媒体排在了独立媒体前面
- 一条中国内地新闻只有官方来源，没有可以对照的独立报道
- 发布产物里出现了任何人的邮箱地址（`npm run privacy`，发布流程里会自动跑）

技术栈：Vite 5 + React 18 + TypeScript（strict）+ react-router-dom（HashRouter）。
没有 UI 框架，样式全部是手写 CSS 和一套语义化设计令牌。
