# PRISM 棱镜

每日更新的全球女性主义与 LGBTQIA+ 新闻与研究站。

网站做的事情很简单：搜集各地相关的新闻和公开研究，为每一条写一段**简短总结**，
再附上**报道这条新闻的媒体链接**。读者顺着链接自己去读原文，事实核查由站长自己承担，
网站不下任何「是真是假」的结论。

配套一个**两页的控制端**：一页启动搜集，一页编辑。

---

## 先看看长什么样

不想装任何东西：双击仓库根目录的 **`PRISM-prototype.html`**，浏览器直接打开，
整个网站（含控制端）都在这一个文件里。

> 这个文件是**某一次构建的快照**，不会自己跟着代码更新。
> 改过代码之后想要一份新的，运行 `npm run single`。线上版本以 GitHub Pages 为准。

想在本地跑开发版：

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

## 网站结构

**公众站**

| 地址 | 是什么 |
| --- | --- |
| `#/` | 今日：站长指定的头条，加上全部新闻，按地区和议题筛 |
| `#/news/:slug` | 一条新闻：总结、要点、所有媒体链接 |
| `#/region/:key` | 某个地区的全部条目 |
| `#/topic/:key` | 某个议题的全部条目 |
| `#/studies` | 研究与公开数据 |
| `#/about` | 关于 |

**控制端**（`#/console`）只有两页：

- **找新闻** — 选地区和议题，按一个大按钮就开始搜。找到的可以直接上线，也可以先存草稿。
- **编辑** — 四个标签：内容 / Claude / 外观 / 账号与同步。

## 一条新闻长什么样

```
标题
总结（想写多长写多长，几百上千字都行，空一行分段）
几条要点
原始文件：判决书、法案、数据集……
媒体报道：报道这条新闻的媒体，每条都能点开
```

长总结在首页信息流里收起，下沿渐隐并带一个「读全文」，点进去看全部。

一条新闻可以同时挂**多个地区标签和多个议题标签**——一份跨国报告本来就属于好几个地方。

**头条由站长指定**，不是算法挑的：在编辑页任意一条上按「设为头条」，它就上首页最上面那个位置。
头条一次只有一条，设了新的旧的自动让位；下架一条就自动不再是头条。
没有指定时，首页用最新的一条顶上，不会开着一个空位。

## 地区

十四个地区：中国内地 · 香港 · 台湾 · 日韩 · 美国 · 欧洲 · 澳新 · 东南亚 · 南亚 ·
中东与北非 · 撒哈拉以南非洲 · 拉丁美洲 · 俄罗斯与中亚 · 跨区域/国际机构。

其中六个（中国内地、香港、台湾、日韩、美国、欧洲）在搜集时会先扫。
这是站长的搜集顺序，只在控制端里出现——公众站上地区就是地区列表，
不告诉读者网站内部怎么排先后。

## 登录与权限

**任何人都可以用 Google 账号登录**——登录本身不解锁任何东西，网站内容不登录也随便看。
只有站长和管理员的账号菜单里才会出现「进入控制端」；别的账号看到的就是一个普通的
已登录状态，不会有一个按了会被拒绝的按钮在那里晃。

站长身份在代码里只以 **SHA-256 哈希**的形式存在（`src/lib/owner.ts`）——
发布出去的文件里没有任何人的邮箱地址。登录时把地址算一遍哈希比对，
地址本身只留在站长自己的浏览器里。只有站长能增删管理员。
管理员能编辑内容、调外观、启动搜集；站长额外能暂停整站显示和恢复初始内容。
站长这一行在名单里**删不掉**——否则控制端会变成没人管得了。

要让登录按钮出现，需要先在「编辑 → 账号与同步」里填一个 Google 客户端 ID
（那一页里写了怎么申请，四步）。

**还没填客户端 ID 的时候，控制端是开着的**，顶部会明说这一点。
这不是漏洞是必须：没接登录时网站根本不知道谁是谁，按身份拦人既拦不住谁，
又会把站长锁在唯一能填客户端 ID 的那一页外面。填好之后门就锁上了。

> **一句实话**：这是一个纯静态网站，登录只能挡住界面，挡不住真正懂技术的人。
> 要做到别人完全打不开控制端，需要一台服务器在后台校验身份。在那之前，
> 请把这里当成「防止误操作」，而不是「防止入侵」。这句话在控制端里也写着。

## 来源怎么选

报道部分**优先采用独立与境外媒体**。判决书、法案、统计表这类原始文件照常收录，
排在最前并标为「官方文件」。

在新闻不自由的地方，官方媒体是政府自己的说法，不是独立的第三方记述。
这类来源不会被删掉——它说了什么本身就是信息——但会在页面上标成「官方媒体」，
读者自己判断怎么读。这条规则在控制端里是一个可关的开关（默认打开），
关掉只影响排序和标注，不会改变收录的链接数量。

数据检查会挡下一条只有官方来源、没有任何可对照独立报道的中国内地条目。

## 控制端里的 Claude

「编辑 → Claude」是一个聊天框。填上 Anthropic API key 之后，它读得到网站当前的
全部内容，并且能真的动手改：外观、网站上写的字、新闻的标题总结要点标签、
设头条、下架和重新上线。说完就改好了，每一步都进「最近编辑」，随时可以撤销。

**它改不了代码。** 这是一个纯静态网站，页面提前构建好再传上去；加新板块、
改版面结构、加新功能都要改源码、重新构建、重新部署，浏览器里一件都做不了。
碰到这类要求，它会写一份能直接交给 Claude Code 的需求，一键开成 GitHub issue。
推送之后 Actions 会自动重新发布。

不填 key 也能用，退回到内置的关键词规则（「字大一点」「换成深色」这类）。
key 只存在这台电脑的浏览器里，跟 GitHub token 一样，随时可以在 Anthropic 后台吊销。

控制端是**按需加载**的，所以读者打开公众站时不会下载 Claude SDK。

## 用哪个 AI 去搜资料

**找资料**可以用免费的开源模型（Qwen / Llama / Mistral / 自建端点），也可以用 Claude——
在「找新闻」页面里选。找链接是重复劳动，不必花钱。

**控制端里的改写**固定使用 Claude，不可切换。

## 内容与外观

- 四套主题（暖纸 / 白纸 / 深色 / 高对比），五种强调色，五档字号，黑体/宋体，宽窄行距。
- 公众站右上角「外观」和控制端「编辑 → 外观」调的是同一套设置，读者也能自己调。
- 「一句话调整」用大白话改外观和网站上写的字，比如「字大一点」「换成深色」。
  它**看不懂就直说**并给一句建议，绝不乱改；改完随时能撤销；它不会动新闻内容，也不会动代码。

## 存回 GitHub

「编辑 → 账号与同步」里填一个 GitHub token（只需要 Contents 的写权限），
就能把当前所有内容存回仓库。存的是一个**内容文件**（`site-content.json`），不是代码，
所以同步不会弄坏网站。token 只存在你自己这台电脑的浏览器里，不会进同步文件。
没有 token 也没关系——旁边有「下载文件」，下载下来自己上传即可。

## 安全与隐私

完整操作手册在 **[docs/SECURITY.md](docs/SECURITY.md)**，两部分：真正的门禁怎么做，
以及怎么让公开的地方不出现你的姓名和账号。

一句话版本：控制端的登录是**界面上的**判断，懂技术的人能绕过去看到界面；
但他改不了你发布的网站——真正更新内容需要 GitHub token，那串东西只在你的浏览器里，
从来没进过发布出去的文件。要连界面也挡住，需要一个自己的域名加 Cloudflare Access
（服务端拦截，免费），手册里写了每一步。

## 发布到网上

仓库里带了 `.github/workflows/pages.yml`。第一次使用前，去仓库的
**Settings → Pages**，把 **Source** 选成 **GitHub Actions**。之后每次推送代码，
网站会自己重新发布。发布前会先跑数据检查和行为测试，不通过就不发布。

## 演示数据

仓库里现在装的是**演示数据**，条目、媒体名称与链接全部虚构，用于展示界面。
所有演示链接都落在保留域名 `.invalid` 上，永远不会解析，在页面上显示为不可点击的
「示例」，不会被误当成真实引用。接入真实检索后，真实链接会正常显示为可点击的链接。

公众站顶部有一条「演示数据」提示条，接入真实内容后会自动消失。

## 开发

```bash
npm run dev        # 开发服务器
npm run build      # 类型检查 + 构建到 dist/
npm run check      # 类型检查 + 数据检查 + 42 项行为测试
npm run privacy    # 扫一遍构建产物，出现邮箱地址就不给发布
npm run ui-check   # 用真实浏览器走 9 条路由 × 3 个视口
npm run single     # 生成单文件 PRISM-prototype.html
npm run artifact   # 打包成一页，用于 claude.ai artifact
```

`npm run check` 是真正的门槛，不是摆设。它会挡住这些事：

- 一条新闻没有任何链接（读者没法自己去核对）
- 演示条目用了看起来像真的网址
- 一份研究没写「这份研究说不了什么」
- 站长被从管理员名单里删掉
- 同步文件里混进了 GitHub token
- 「一句话调整」在看不懂时仍然乱改
- 撤销一次搜集之后没有把这次加的全部收回
- 同时有两条头条，或者头条是下架状态（读者看不到）
- 接上登录之后，不在管理员名单里的账号还进得去控制端
- 打开取材规则之后，官方媒体排在了独立媒体前面
- 一条中国内地新闻只有官方来源，没有可以对照的独立报道
- 发布产物里出现了任何人的邮箱地址（`npm run privacy`，发布流程里会自动跑）

技术栈：Vite 5 + React 18 + TypeScript（strict）+ react-router-dom（HashRouter）。
没有 UI 框架，样式全部是手写 CSS 和一套语义化设计令牌。
