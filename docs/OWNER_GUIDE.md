# 站长手册

写给不做技术的人看的。照着做就行，看不懂的地方都可以不动。

---

## 一、第一次打开

双击仓库里的 **`PRISM-prototype.html`**，浏览器就打开了整个网站。
右上角有个「控制端」按钮，点进去就是你管理网站的地方。

网站现在装的是**演示数据**：里面的新闻、媒体名字、链接全是编的，只是给你看界面长什么样。
顶上那条「演示数据」的提示，等换成真内容之后会自己消失。

---

## 二、控制端只有两页

### 第一页：找新闻

> ⚠️ **这一页是原型，不要拿它给读者发内容。**
>
> 界面上这个「开始搜集」按的是一个**演示引擎**：它从一个虚构素材池里取材，
> 链接全是 `.invalid` 假域名（页面上会标成「示例链接」）。它存在是为了让你
> 看清整个流程长什么样，**不是真的在搜新闻**。
>
> **真的收集在 GitHub Actions 里跑**，见下面「真实新闻收集」。它订阅真实媒体的
> RSS，写进来的每一条都带真实链接，而且**一律先下架**，等你审过才上线。

1. 选**搜哪些地区**。你点名的六个（中国内地、香港、台湾、日韩、美国、欧洲）默认就选好了，
   上面标着「优先」。想只搜这六个，点右上角「只搜优先六个」。
2. 选**搜哪些议题**。默认全选。
3. 按那个大按钮 **开始搜集**。

下面几个设置都有默认值，看不懂可以不动：

| 设置 | 打开会怎样 | 关掉会怎样 |
| --- | --- | --- |
| 找到就直接上线 | 新内容马上出现在公众站，你随时可以删 | 先存成草稿，等你放行 |
| 自动跳过重复的 | 和已有内容很像的就不再加一遍 | 允许重复 |

搜完会告诉你**加了几条**，还会列出**哪些被跳过了、为什么**——不会有东西悄悄消失。
不满意就按「撤销这次搜集」，这一批全部收回。

**用哪个 AI 去找**：找链接是重复劳动，用免费的开源模型就够了，不用花钱。

### 真实新闻收集（GitHub Actions）

真正去订阅媒体、抓真实新闻的是 `.github/workflows/collect.yml`。

**它每天早上跑一次**（北京/台北时间 6 点），把新条目写进数据库，**全部是下架状态**。
你打开「编辑 → 内容」，把筛选切到「已下架」，一条条看：

- 想发的 → 按「**重新上线**」，读者立刻看得到
- 不想发的 → 按「**永久删除**」，或者就放着

**没有任何一条会绕过你自己上线。**

#### 现在就能试（不需要任何配置）

GitHub 仓库 → **Actions** → 左边选「**找新闻**」→ 右上 **Run workflow**。

没配密钥时它只做**演练**：不写数据库，但会把 27 个来源逐个报一遍——哪些能用、
各抓到几条。源会换地址、会关站，这份报告就是用来发现的。

#### 让它真的写进数据库

要两个 GitHub Secret（仓库 → Settings → Secrets and variables → Actions → New repository secret）：

| 名字 | 填什么 |
| --- | --- |
| `SUPABASE_URL` | 你的 Project URL，`https://你的项目ID.supabase.co` |
| `SUPABASE_SERVICE_KEY` | Supabase → Settings → API Keys 里的 **Secret key** |

> **这里的 Secret key 和网站上那个不一样。** 网站里绝对不能填 Secret key——
> 那等于把绕过所有权限的钥匙印在公开网页上，控制端会当场拦下你。
> 但 GitHub Secret 是**服务器端**的保险箱，只有 Actions 读得到，
> 永远不会进任何人的浏览器。收集脚本要写数据库，只能用它。

#### 换来源

来源清单在 `scripts/feeds.mjs`，每一条都写了**为什么收它**。选源标准也写在那个文件
开头——通讯社与一手文件优先、独立媒体次之、国家资助的收录但标注出来。
想加想删，直接跟 Claude Code 说。

### 第二页：编辑

三个标签，从最常用排到最少用。

**内容** — 先用「新闻／研究」切到要改的那一类，两边都有一个
「**＋ 自己写一条**」（切到研究那边就是「＋ 自己写一项研究」）。按下去多一条空白的，
卡片自己展开等你写；点开已有的任意一条也能编辑。

新建的**一律先是下架状态**——一条只有「（未命名）」的空壳出现在首页上，
比没有这条更糟。写好按「重新上线」，那是你的决定。列表里标「你写的」，
跟搜集回来的分得清。

新闻能改：

- 改标题、改总结（**想写多长写多长，几百上千字都行，空一行分段**）、改要点
- 加或去掉地区/议题标签（一条可以挂好几个）
- **每一个媒体链接都能单独删掉**，也能自己加新的
- **「设为头条」**：这一条就上首页最上面那个大位置
- 编辑完按「保存」

研究能改的是读者在研究卡上看得到的每一样东西：标题、来源机构、发布日期、
类型（决定读者看到的可信度标签）、总结、**关键数字**（每个数字旁边都要写
「它说不了什么」，否则读者会把它当成全部事实）、**这份研究说不了什么**、
数据下载链接、原文与报道链接。同样是改完按「保存」。

不想让别人看到，按「**下架**」——内容还在，随时能恢复。
确定不要了，才按「**永久删除**」——这个撤不回来，会先问你一次。

**头条怎么定**

首页最上面那个大位置叫头条，**由你说了算**，不是网站自己挑的。

- 在任意一条上按「设为头条」就行。
- 一次只有一条头条。设了新的，旧的自动让位，「最近编辑」里会写清楚是哪一条让了位。
- 把头条下架，它就自动不再是头条（看不见的东西当不了头条）。
- 你没指定的时候，首页会用最新的一条顶上，不会空着。

> **控制端里原来有一个「Claude」标签，已经去掉了。**
> 想改网站——不管是改文字、改样子，还是加新功能——**直接在 Claude Code
> 的聊天里说**就行，那边能真的改代码、跑测试、重新发布。
> 网站里再放一个功能弱一截的复制品没有意义，还平白多一个把 API key
> 存进浏览器的理由。

**外观** — 手动调字号、主题、强调色、字体、行距，以及网站名称、副标题、首页那段介绍。
这些设置公众站和控制端同时生效，读者自己也能在网站右上角调。

**账号与同步** — 见下面第三、四节。

## 三、让朋友也能看

**要紧的一件事**：现在把网址发给朋友，他看到的是**演示数据**，不是你的内容——
因为内容存在你自己的浏览器里，没有一个大家共用的地方。

要真的分享出去，接一个免费的共享数据库，十五分钟，只做一次。
完整步骤在 **[SHARING.md](SHARING.md)**，控制端「编辑 → 账号与同步 →
让朋友也能看」里也有同样的三步。

接上之后：朋友输邮箱 → 收到一封信 → 点链接就进来了，不用设密码。
你决定谁只能看、谁能编辑。权限由数据库把关，改浏览器里的代码没用。

## 四、登录和成员

**这一节只在你接上共享数据库之后才有意义**（见上一节）。没接之前，
内容只存在你这台浏览器里，没有第二个人，所以也没有登录这回事——
控制端直接打开就能用。

接上之后：

- **朋友用邮箱登录**：输入邮箱 → 收到一封信 → 点里面的链接。
  不用设密码，不用 Google 账号，不用装任何东西。
- **三种身份**：

  | 身份 | 能做什么 |
  | --- | --- |
  | **站长**（你） | 全部。唯一能增删成员、改别人身份的人 |
  | **编辑** | 改内容、发内容、启动搜集。不能动成员名单 |
  | **成员** | 跟没登录的人一样能看。登录只是让站长知道是谁、以后能发通知 |

- **看内容不需要登录**：把网址发给朋友，他打开就能看。
  链接就是门禁——转发给谁，谁就能看。
- **写入需要权限**：只有站长和编辑能改，由数据库强制执行，
  改浏览器里的代码没有用。成员名单也锁着，里面是朋友们的邮箱。
- **站长那一行删不掉也降不了级**，这是故意的，防止你把自己锁在外面。
- 代码里**不写死任何人的邮箱**。谁是站长来自数据库，所以发布出去的文件里
  没有任何人的地址（细节见 [SECURITY.md](SECURITY.md)）。

怎么加人、朋友那边会看到什么，完整步骤在 **[SHARING.md](SHARING.md)** 第五步。

## 五、把内容存回 GitHub

在「编辑 → 账号与同步」里填一个 GitHub token（申请时只需要勾 Contents 的写权限），
按「同步到 GitHub」，当前所有内容就存回你的仓库了。

存的是一个**内容文件**，不是代码，所以同步不会弄坏网站。
token 只留在你自己这台电脑的浏览器里，也不会被写进同步的文件里。

**没有 token 也行**：旁边有「下载文件」，下载下来自己传上去，效果一样。

做「恢复初始内容」这种大动作之前，建议先下载一份备份。

## 六、发布到网上

仓库里已经带好了发布用的配置。你只要做一次：

1. 打开仓库页面 → **Settings**（设置）
2. 左边找到 **Pages**
3. **Source**（来源）选成 **GitHub Actions**

之后每次推送代码，网站会自己重新发布。
发布前会先自动跑一遍检查，不通过就不发布，坏页面上不了线。

### 网址里不要出现你的名字

GitHub Pages 默认给的网址是 `你的账号名.github.io/仓库名/`，账号名里带姓名就会露出来。
三个办法，从最省事到最彻底：

| 办法 | 网址会变成 | 花费 | 说明 |
| --- | --- | --- | --- |
| 建一个**组织**，把仓库转过去 | `prismlens.github.io/PRISM/` | 免费 | 组织名自己起，跟你的个人账号名无关 |
| 改**个人账号名** | `新名字.github.io/PRISM/` | 免费 | 会影响你名下所有仓库的旧链接 |
| 买一个**自己的域名** | `prismlens.org` | 约 ¥80–150/年 | 最干净，也最像一个正经媒体 |

**推荐组合**：先建组织（免费、立刻解决露名问题），以后想要正式域名再加，两者不冲突。

**建组织**：GitHub 右上角头像 → Your organizations → New organization → 选免费方案 →
起一个跟站点有关的名字。然后在仓库的 Settings → 最下面 Transfer ownership，转给这个组织。
转完之后 Pages 要重新按上面三步开一次。

**用自己的域名**：

1. 在任意一家域名商买下域名。
2. 在域名商的 DNS 设置里加四条 A 记录，指向 `185.199.108.153`、`185.199.109.153`、
   `185.199.110.153`、`185.199.111.153`；再加一条 `www` 的 CNAME 指向 `你的组织名.github.io`。
3. 在仓库里新建文件 `public/CNAME`，内容就一行，你的域名，比如 `prismlens.org`。
   <br>（用 Actions 发布时，域名必须写在 `public/CNAME` 里才会被打包进去。）
4. 仓库 Settings → Pages → Custom domain 填上同一个域名，勾上 **Enforce HTTPS**。

DNS 生效通常几分钟到几小时。换域名不影响登录——邮箱登录不绑定域名。

## 七、发布之后想改东西

分两类，体验完全不同：

**改内容** —— 在控制端里直接改。

「编辑 → 内容」：按「＋ 自己写一条」加新的（新闻和研究都能写），点开任意一条改
标题、总结、要点、标签、链接，设头条，下架，永久删除。改完就生效，
全部记进「最近编辑」。
外观和网站上写的字在「编辑 → 外观」里调。这类占日常修改的绝大多数，
不需要任何人帮忙。

**改代码**（加新板块、加新页面、改版面结构、加新功能）—— **直接在 Claude Code
的聊天里说**：「首页加一个按时间排的列表」「把研究那一页改成两栏」。
它改代码、跑测试、推送，GitHub Actions 自动重新构建并发布，一两分钟后网站就更新了。

为什么这一步在网站里做不到：这是一个纯静态网站，页面是提前构建好再传上去的。
改源码、重新构建、重新部署这三件事，浏览器里一件都做不了——所以控制端里
曾经那个 Claude 标签，本来也只能改内容和外观，改不了代码。既然改内容
在「内容」标签里就能做，它就没有存在的必要了。

## 八、出事了怎么办

| 情况 | 怎么办 |
| --- | --- |
| 误删了一条新闻 | 永久删除撤不回来。所以平时不确定就用「下架」 |
| 调乱了外观 | 「编辑 → 外观」里一个个调回来；实在乱了就在 Claude Code 里说一句「恢复默认外观」 |
| 头条不对 | 去你想要的那一条上按「设为头条」，旧的自动让位 |
| 想加个新板块/新页面 | 直接在 Claude Code 的聊天里说（见第七节）|
| 搜回来一批不想要的 | 那次搜集下面有「撤销这次搜集」 |
| 想暂时关掉整个网站 | 「编辑」最下面的「暂停显示」（只有站长能按）。内容不会被删 |
| 想全部推倒重来 | 「恢复初始内容」。**先下载备份**，这个撤不回来 |

每一步编辑都记在「编辑」页面下面的 **最近编辑** 里，包括是谁做的、什么时候做的。
