# 站长手册

写给不做技术的人看的。照着做就行，看不懂的地方都可以不动。

---

## 一、第一次打开

双击仓库里的 **`PRISM-prototype.html`**，浏览器就打开了整个网站。
右上角有个「控制端」按钮，点进去就是你管理网站的地方。

网站现在装的是**演示数据**：里面的新闻、媒体名字、链接全是编的，只是给你看界面长什么样。
顶上那条「演示数据」的提示，等换成真内容之后会自己消失。

---

## 二、控制端只有两页

### 第一页：找新闻

1. 选**搜哪些地区**。你点名的六个（中国内地、香港、台湾、日韩、美国、欧洲）默认就选好了，
   上面标着「优先」。想只搜这六个，点右上角「只搜优先六个」。
2. 选**搜哪些议题**。默认全选。
3. 按那个大按钮 **开始搜集**。

下面几个设置都有默认值，看不懂可以不动：

| 设置 | 打开会怎样 | 关掉会怎样 |
| --- | --- | --- |
| 找到就直接上线 | 新内容马上出现在公众站，你随时可以删 | 先存成草稿，等你放行 |
| 自动跳过重复的 | 和已有内容很像的就不再加一遍 | 允许重复 |

搜完会告诉你**加了几条**，还会列出**哪些被跳过了、为什么**——不会有东西悄悄消失。
不满意就按「撤销这次搜集」，这一批全部收回。

**用哪个 AI 去找**：找链接是重复劳动，用免费的开源模型就够了，不用花钱。
控制端里的改写固定用 Claude，这个不用你管。

### 第二页：编辑

四个标签，从最常用排到最少用。

**内容** — 点开任意一条新闻就能编辑：

- 改标题、改总结、改要点
- 加或去掉地区/议题标签（一条可以挂好几个）
- **每一个媒体链接都能单独删掉**，也能自己加新的
- **「设为头条」**：这一条就上首页最上面那个大位置
- 编辑完按「保存」

不想让别人看到，按「**下架**」——内容还在，随时能恢复。
确定不要了，才按「**永久删除**」——这个撤不回来，会先问你一次。

**头条怎么定**

首页最上面那个大位置叫头条，**由你说了算**，不是网站自己挑的。

- 在任意一条上按「设为头条」就行。
- 一次只有一条头条。设了新的，旧的自动让位，「最近编辑」里会写清楚是哪一条让了位。
- 把头条下架，它就自动不再是头条（看不见的东西当不了头条）。
- 你没指定的时候，首页会用最新的一条顶上，不会空着。

**一句话调整** — 用大白话说你想怎么调，比如：

> 字大一点 · 换成深色 · 强调色改成靛蓝 · 把网站标题改成「棱镜观察」

它只调**外观**和**网站上写的字**，不会动新闻内容，也不会动代码。
最坏的情况就是你不喜欢，按「撤销刚才这次」回去。
**看不懂它会直说**，并给你一句建议，不会瞎猜着乱调。

**外观** — 手动调字号、主题、强调色、字体、行距，以及网站名称、副标题、首页那段介绍。
这些设置公众站和控制端同时生效，读者自己也能在网站右上角调。

**账号与同步** — 见下面第三、四节。

## 三、登录和管理员

**看网站不用登录。** 任何人都可以用 Google 账号登录，但登录本身不解锁任何东西——
它只是让网站知道你是谁。

- 站长是 **mingshen.lu0802@gmail.com**，只有站长能加管理员、删管理员。
- 加进来的人是**管理员**：能编辑内容、调外观、启动搜集。
- 站长这一行删不掉，这是故意的——不然控制端会变成没人管得了。
- **只有你（和你加的管理员）登录时，账号菜单里才会出现「进入控制端」。**
  别人登录看到的就是一个普通的已登录状态，不会有一个按了会被拒绝的按钮。

**要让登录按钮出现，得先申请一个 Google 客户端 ID**，控制端里写了四步怎么做。
只做一次，做完就不用再管。

> 在你填好客户端 ID 之前，**控制端是开着的**，页面顶部会明说这件事。
> 这是必须的：没接上登录的时候网站根本不知道谁是谁，这时候拦人既拦不住，
> 又会把你自己锁在唯一能填客户端 ID 的那一页外面。填好之后门就锁上了。

> 要知道的一件事：这是一个纯静态网站，登录只能挡住界面，挡不住真正懂技术的人。
> 想做到别人完全打不开控制端，需要一台服务器在后台校验身份。
> 在那之前，请把这里当成「防止误操作」，不是「防止入侵」。

## 四、把内容存回 GitHub

在「编辑 → 账号与同步」里填一个 GitHub token（申请时只需要勾 Contents 的写权限），
按「同步到 GitHub」，当前所有内容就存回你的仓库了。

存的是一个**内容文件**，不是代码，所以同步不会弄坏网站。
token 只留在你自己这台电脑的浏览器里，也不会被写进同步的文件里。

**没有 token 也行**：旁边有「下载文件」，下载下来自己传上去，效果一样。

做「恢复初始内容」这种大动作之前，建议先下载一份备份。

---

## 五、发布到网上

仓库里已经带好了发布用的配置。你只要做一次：

1. 打开仓库页面 → **Settings**（设置）
2. 左边找到 **Pages**
3. **Source**（来源）选成 **GitHub Actions**

之后每次推送代码，网站会自己重新发布。
发布前会先自动跑一遍检查，不通过就不发布，坏页面上不了线。

## 六、出事了怎么办

| 情况 | 怎么办 |
| --- | --- |
| 误删了一条新闻 | 永久删除撤不回来。所以平时不确定就用「下架」 |
| 调乱了外观 | 「一句话调整」里说「恢复默认外观」 |
| 头条不对 | 去你想要的那一条上按「设为头条」，旧的自动让位 |
| 搜回来一批不想要的 | 那次搜集下面有「撤销这次搜集」 |
| 想暂时关掉整个网站 | 「编辑」最下面的「暂停显示」（只有站长能按）。内容不会被删 |
| 想全部推倒重来 | 「恢复初始内容」。**先下载备份**，这个撤不回来 |

每一步编辑都记在「编辑」页面下面的 **最近编辑** 里，包括是谁做的、什么时候做的。
