## 二、PRISM Command（终极控制端）

进入方式：页面右上角「进入 PRISM Command」，或直接访问 `/command`。

### 1. 总览
`/command` — 今日五个重要事件、待审核文章、最新研究、高风险内容、引用检查失败项目、
已排程与已发布、需要更新的旧文章、全球议题与来源分布，以及自动编辑台当日七个阶段的运行记录。
注意最后一个阶段：编辑台只能「移交等待审批」，没有发布权限。

### 2. 审批队列与发布前确认
`/command/queue`

1. 切换到「高风险」标签，打开 **马兰群岛** 那一篇。
2. 点「批准并立即发布」。
3. 发布前确认流程会依次要求：
   - 逐条阅读硬阻断项（引用检查失败、未处理的极高风险、封面图未审）；
   - 勾选每一条警告；
   - 对性暴力、未成年人、司法程序进行中、身份暴露四类内容**逐项确认**；
   - 键入确认短语「确认发布」；
   - 最后再看一次「即将发生什么」。
4. 试试其余六种决定：批准并排程 / 保存草稿 / 要求增加来源 / 退回重新研究 / 拒绝 / 归档。
   后四种都必须写明理由，理由会进入操作记录。

### 3. 文章工作台与 Further Vibe Coding
`/command/article/art-maran`（或从队列点进任意一篇）

- **左栏**：来源（按证据层级排序、可信度依据、候选来源可一键「加入本文」）、研究、法律文件、今日信号。
- **中栏**：文章正文，可点击就地编辑；行内引用、图表、图片、多语言版本切换（机器初稿会明确标注）。
- **右栏**：
  - *AI 编辑助手*：编辑台核实了什么、没核实什么、哪些句子只有单一来源支撑。
  - *Further Vibe Coding*：输入自然语言指令，例如
    「加入澳大利亚法律背景。」（本原型中请用虚构辖区，如「加入北屿的法律背景」）、
    「增加当地女性主义组织的观点。」、
    「检查是否存在受害者有罪论。」、
    「重新核查每个 reference。」、
    「把文章改得更深入。」、
    「更换一张不呈现受害者形象的封面图。」
    每次都会生成**新版本提案**，显示修改理由、差异与 references 增删，并等待你确认后才采用。
  - *事实检查*：逐条引用的核查状态与失败原因，可一键重新核查。
  - *风险提示*：每条风险的处置指引，标记为已处理需写明处置说明。
  - *发布控制*：发布闸门读数 + 七种决定。

### 4. 版本比较
`/command/article/art-maran/versions` — 版本时间线、并排对照与行内标注两种差异视图、
references 增删清单。采用某个版本不会销毁历史：所有旧快照都保留。

### 5. 图像与视觉素材
`/command/article/art-maran/studio` — 生成封面图、地图、数据图表、时间线与社交素材。
AI 图一律标注「概念插图 · AI 生成 · 非新闻现场」；伦理约束字段不可为空；
数据图表必须选择既有数据集，并显示「数据来源」与「本图无法说明」两行。

### 6. 今日信号、研究雷达、来源库
- `/command/signals` — 多国多语言搜集、重复报道合并、选题价值评估；未采用的选题保留理由，不会静默消失。
- `/command/research` — 最新研究（预印本会明确标注「未经同行评审」）与正在传播的可疑说法。
- `/command/sources` — 来源库全表与全球／语言／类型分布。

### 7. 每日编辑简报
`/command/brief` — 同时提供控制端视图与邮件预览。邮件里只有摘要与安全链接，
没有任何可以发布内容的按钮。

### 8. 操作记录
`/command/audit` — 所有搜集、起草、修改、审批、发布、撤回与锁操作的完整记录。

### 9. 引擎分配
`/command/settings` — 「引擎分配」面板。
资料检索可在开源模型（Llama / Mistral / Qwen / 自定义端点）与 Claude 之间切换；
起草与改写固定为 Claude，面板上是只读状态。
切换后到 `/command/signals` 可以看到当前检索引擎。

### 10. Global Publishing Lock
`/command/settings`

1. 开启发布锁（需要填写理由）。
2. 返回队列，对任意一篇点「批准并立即发布」。
3. 系统只会记录「已批准」，**不会公开发布**，并在操作记录里写明被发布锁拦截。
4. 解除发布锁后再试一次。

### 11. 操作记录
`/command/audit` — 顶部会统计有多少次「影响公开内容的操作」，并写明其中有几次不是由主编执行的。
在这份演示数据里这个数字是 0：自动编辑台没有发布权限。

## 三、可以直接跑的检查

```bash
npm run validate   # 引用、来源、图表、风险标记与占位链接的完整性
npm run smoke      # 发布闸门、全局锁、七种决定、版本模型与 Vibe 引擎的行为
npm run build && npm run ui-check   # 19 条路由 × 3 个视口的运行时与无障碍检查
```
