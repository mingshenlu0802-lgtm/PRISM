# PRISM 棱镜 · 编辑方法与证据标准

> 本文件既是仓库文档，也是公众页面 `/method` 的内容依据。
> **提醒：本仓库为原型，其中全部条目、来源与数据均为虚构演示内容。**

---

## 0. 权限分配

| 环节 | 由谁完成 |
|------|----------|
| 多国家、多语言搜集 | 自动编辑台 |
| 重复报道合并与选题价值评估 | 自动编辑台，人可推翻 |
| 资源检索（确认引用指向的材料是否存在、可否取得） | 自动编辑台 |
| 判断来源是否可靠、说法是否属实 | 人 |
| 深度文章草稿 | 自动编辑台 |
| 封面图、图表、社交素材 | 自动编辑台生成，人审批 |
| 事实、references、偏见、隐私与法律风险检查 | 自动编辑台生成清单，人判断 |
| **批准与公开发布** | **只有人** |

自动编辑台**没有发布权限**。它唯一能做的最后一步是「移交控制端等待审批」。
未经主编明确批准，所有内容只能停留在草稿状态。

编辑台做的是**资源检索**，不是核查：它确认每条引用指向的材料是否存在、能否取得，
并把结果标记为「资源已找到 / 仅部分可得 / 资源未找到」。
判断来源是否可靠、说法是否属实，是主编的工作。

## 1. 来源政策

### 1.1 优先级
1. 原始研究（同行评审、公开方法与数据）
2. 法律文本与法院判决原文
3. 政府与统计机构的原始数据发布
4. 国际机构的条约机构意见与调查报告
5. 可靠的当地媒体与当地民间组织报告
6. 通讯社报道
7. 公开声明
8. 社交平台内容（仅作为「说法存在」的证据，不作为「说法成立」的证据）

### 1.2 硬性下限
- 每篇文章至少 **2 份一手材料**；低于此数不进入发布流程（`publishGate` 会给出警告）。
- 每个关键事实至少 **2 个独立来源**；独立指的是**不共享同一原始信源**，而不只是不同署名。
- 转载、聚合、二次引用一律回溯到原始文件；找不到原始文件的，标注为「未取得一手记录」。

### 1.3 资源检索
编辑台对每条引用执行一次检索，结果只有三种：**资源已找到 / 仅部分可得 / 资源未找到**。
「已找到」意味着材料存在且可取得，不意味着它可靠。资源未找到的引用在主编记录处理说明之前会阻断发布。

### 1.4 可信度评分
0–100 的分数**永远附带一句可读的依据**，说明方法透明度、独立性、
更正记录与接触一手材料的能力。分数不是黑箱，不用于自动过滤，只用于提示编辑注意力。

### 1.5 不得虚构
不得编造来源、数据、引文、DOI 或任何人的言论。
无法取得的材料写「无法取得」，不用相近材料替代。

## 2. 事实核查结论阶梯

八级结论，每一级都对应一个明确的证据门槛：

| 结论 | 需要满足 |
|------|----------|
| **有充分证据支持** | 多个独立一手来源一致支持，且无同等质量的反证 |
| **基本属实但缺乏语境** | 核心事实成立，但省略了会改变读者理解的关键背景 |
| **部分属实** | 可拆分的部分成立、部分不成立，需逐条说明 |
| **证据存在冲突** | 质量相当的可靠来源结论互斥，现有证据无法判定 |
| **缺乏足够证据** | 证据不足以支持或否定；**不等于该说法为假** |
| **具有误导性** | 所引事实可查证，但呈现方式导致与证据不符的结论 |
| **基本不实** | 核心主张与一手证据相悖，仅剩边缘性真实成分 |
| **无法核实** | 取证受限、来源无法接触或记录不存在；须写明受阻原因 |

每条核查都必须回答：**什么样的新证据会改变这个结论？**
结论被修订时，旧结论与修订理由公开保留，不静默替换。

## 3. 区分事实、推断、指控与司法结论

文章的九个固定章节本身就是这个区分的载体：

1. **事件与核心事实** — 只写可归因到具体来源的内容
2. **法律、历史与社会背景**
3. **权力结构与交叉性分析**
4. **相关研究与数据** — 附方法、样本与局限
5. **不同来源之间的分歧**
6. **事实核查**
7. **尚未确定的信息**
8. **事件为何重要** — 明确标注为编辑分析
9. **后续值得关注的进展**

时间线节点用三种形状标注证据地位：
**已有一手记录（documented）／单一来源报道（reported）／存在争议（contested）**。

用词规则：
- 「指控」用于尚未经审理认定的主张，并注明由谁提出、向谁提出、何时提出。
- 「认定」「判决」只用于司法或行政机关已作出的结论，并注明文号与审级。
- 编辑判断出现在正文时必须自我标注（「本站的判断是……」），不得混入事实陈述。

## 4. 创伤知情与受害者中心

涉及性暴力、家庭暴力与性骚扰的报道：

- **不描写侵害过程**，不使用可满足猎奇心的细节。
- **不描写着装、饮酒、行踪、感情史**，除非该细节本身是司法争点且必须说明。
- **不使用无施害者的被动句**（「一名女性被侵害」→「一名男子被指控侵害一名女性」）。
- 不把暴力称为「纠纷」「情感纠葛」「家庭矛盾」。
- 「声称／据称」不得只挂在当事人一侧，两侧陈述适用同一归因标准。
- 幸存者的选择（是否报案、是否公开、是否和解）不作为可信度的依据。
- **隐私优先于完整性**：地点、职业、亲属关系、就诊机构等可拼合识别的信息逐项检查。
- 所有此类条目必须设置**内容提示**，写明具体涉及的内容类型，并置于正文之前。
- 涉及未成年人、进行中的司法程序或可能暴露身份的内容，**发布前必须逐项勾选并键入确认短语**。

## 5. 分歧与虚假平衡

- 呈现分歧时，为每种立场标注**证据强度**（强／中／弱）并说明理由。
- **不制造虚假平衡**：证据一边倒时就说一边倒，并说明证据基础。
- **也不因为立场契合而降低证据标准**：符合本站价值立场的说法，若证据薄弱，同样标注为薄弱。
- 少数立场若有扎实一手证据支持，不因其少数而降级。

---

## 6. 图像与数据可视化

- **绝不虚构新闻现场，绝不生成真实当事人或受害者的形象。**
- AI 生成图一律标注为**「概念插图 · AI 生成 · 非新闻现场」**，且只使用抽象几何构图。
- 数据图表必须来自具体数据集，图注同时给出**数据来源**与**本图无法说明什么**。
- 置信区间必须画出来；隐藏不确定性视为图表错误。
- 统计口径变更处必须断线并标注，不得跨口径连成一条趋势线。
- 地图为示意投影，且本原型中的司法辖区均为虚构，不对应任何真实地理。

---

## 7. 更正、更新与撤回

- 更正、澄清、更新、撤回四类记录**永久公开保存**，附时间与执行人。
- 已发布内容出现新证据时进入「需更新」队列，不静默修改。
- 撤回时保留原文可访问性说明与撤回理由，不删除历史。

---

## 8. Further Vibe Coding 的边界

自然语言指令可以要求补充背景、增加当地视角、检查受害者有罪论框架、重新核查引用、
加深分析或更换封面图。但：

- **每次修改生成新版本，不覆盖原稿**；差异、新增与删除的 references 一并显示。
- 指令**不能凭空创造来源**；引擎只能从已入库的来源中选取，找不到就明说找不到。
- 采用与否始终需要人再次确认。
- 指令若无法被安全地自动执行，引擎必须明说「未识别为可自动执行的编辑」，
  并给出需要人来决定的问题，**不得静默不做事**。

---

## 9. Global Publishing Lock

主编可随时开启全局发布锁。开启期间：

- 所有公开发布被暂停，包括已排程内容。
- 「批准并立即发布」只记录批准，不公开。
- 锁的开启与解除、原因与执行人写入操作记录。

---

## 10. 不确定性

我们公开承认：搜集不可能穷尽、翻译会丢失语境、缺失数据本身也是一种权力结构的产物。
「尚未确定的信息」是每篇文章的必需章节，不是免责声明。
